# Week 1 — Explorando Modelos de Fronteira: Primeiro Produto LLM

**Seção do curso:** Seção 1 — 36 aulas, 5h 44min

## O que o curso cobre

- Instalação do Ollama e primeiro contato com LLMs locais (Llama 3.2)
- APIs de fronteira: OpenAI, Anthropic Claude, Google Gemini
- Comparação entre modelos: capacidades, custos, contexto
- Construção de um produto LLM funcional com Gradio
- Engenharia de prompts: system prompts, roles, context window
- Agentes simples: tool use e function calling introdutório
